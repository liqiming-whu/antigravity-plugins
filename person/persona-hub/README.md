# 人设控制台 (Persona Hub)

Antigravity 侧边栏（Auxiliary Pane）实时人设与会话状态面板插件。

## 功能特性
- **当前激活人设展示**：自动识别当前启用的 `*-persona` 插件（如哈基米、小克等），默认展示**写实形象**，支持一键切换查看**二次元成年版形象**。
- **动态图鉴与热发现**：无需修改代码，新增任何 `<name>-persona` 插件目录后每 5 秒自动扫描纳入图鉴，支持未激活状态下点击预览立绘与复制唤醒词。
- **无人设 / 多人设容错**：当未激活任何人设插件时自动回退展示「默认助手模式」卡片；当同时开启多个人设时顶部显示冲突提醒。
- **会话与调用统计**：实时展示当前对话模型档位、交互步数/提问轮数、今日总交互步数/生图次数，以及当前对话上下文体积负载条。
